# Assets and credits

All truck bodies, wheels, robot parts, bears, alligators, trees, hills, clouds, road geometry, icons, and garage illustrations are generated from the original code in this project. All sound effects and engine tones are synthesized by `src/audio.mjs`. The game uses system fonts.

There are no downloaded character models, branded vehicle logos, texture packs, stock photographs, or third-party audio recordings.

Rendering uses [Three.js](https://threejs.org/), distributed under the MIT license. Its copyright and permission notice ships in the built game as `THREE-LICENSE.txt`. Vite and Playwright are development tools; their package license files are supplied with their installed packages.

Project screenshots in `docs/screenshots/` show this game's actual browser rendering. They are not concept art.
